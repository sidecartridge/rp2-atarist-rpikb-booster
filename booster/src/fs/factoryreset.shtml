Factory Reset

This will erase all device configuration — Wi-Fi credentials, Bluetooth pairings, keyboard / mouse / joystick settings, and the boot mode — and reboot the device into Booster (configuration) mode so it can be set up from scratch.

! This action cannot be undone. All paired Bluetooth devices will need to be re-paired.
